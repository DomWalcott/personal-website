Projects

Weather App

HTML - CSS - JavaScript
This was one of the first front end projects that I completed. It uses the standard frontend set up of HTML, CSS and JavaScript and an open weather API to fetch the current temperature of any city or town.

It is very minimalistic in its design, but I wanted to make something that required the use of an API. It didnt take long to create and it is far from being perfect, but I was a good learning experience.

BMI calculator

HTML - CSS - JavaScript
In my role as physiotherapist, I would often have to calculate the BMI of patients. Normally, I would search for a BMI calculator on google and use that to work it out. Since I was looking for a coding project to get stuck into, I thought it might be a good idea to build a BMI calculator myself.

This is another purely front end application using HTML, CSS and Javascript. You enter your height in metres and your weight in Kg and it will calculate your BMI. This is the first application I built where i had to consider the edge cases when considering the inputs for height and weight.

Sudoku Solver

HTML - CSS - JavaScript - C# - ASP.Net Core Web API
I wanted to create an application that utilised custom built API. While this could have been a solely front end application, I wanted to create the frontend, the back end in C# and an API.

This application will accept a sudoku puzzle and return a solved sudoku puzzle.
